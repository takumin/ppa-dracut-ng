Personal Package Archive for dracut-ng

dracut-ng is an event driven initramfs infrastructure, and the actively maintained successor of dracut.

The official Apt repositories of Debian stable and Ubuntu LTS ship older versions of dracut.

This PPA repository rebuilds the latest dracut package maintained by the Debian Kernel Team for each supported platform.

Supported platforms

  • Debian 12 (bookworm)
  • Debian 13 (trixie)
  • Ubuntu 24.04 LTS (noble)
  • Ubuntu 26.04 LTS (resolute)

Supported architectures

  • amd64
  • arm64

Install required packages

sudo apt-get update
sudo apt-get install wget ca-certificates

Download GPG public key

sudo mkdir -p -m 0755 /etc/apt/keyrings
sudo wget -O /etc/apt/keyrings/ppa-dracut-ng.asc https://takumi.tmfam.com/ppa-dracut-ng/public.gpg.asc

Verify GPG public key

gpg --show-keys /etc/apt/keyrings/ppa-dracut-ng.asc
pub
@GPG_PUB@
fpr
@GPG_FPR@
uid
@GPG_UID@

Configure APT sources

cat <<EOF | sudo tee /etc/apt/sources.list.d/ppa-dracut-ng.sources
Types: deb deb-src
URIs: https://takumi.tmfam.com/ppa-dracut-ng
Suites: $(. /etc/os-release && echo "${VERSION_CODENAME}")
Components: main
Signed-By: /etc/apt/keyrings/ppa-dracut-ng.asc
EOF

Install dracut package

Note: Installing the dracut package removes initramfs-tools.

sudo apt-get update
sudo apt-get install dracut
